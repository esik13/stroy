# Основа — сайт строительной компании

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория (файл `index.html` должен лежать прямо в корне).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. Подождите завершения публикации и откройте адрес, который покажет GitHub Pages.

## Важно

- Сайт адаптирован для статического хостинга GitHub Pages: страницы, стили, JavaScript, калькулятор и интерфейс работают без Node.js.
- GitHub Pages не запускает Node.js и SQLite. Поэтому серверная админ-панель и база заявок не входят в эту публикационную сборку.
- Форма на сайте пока не отправляет заявки: для реального приёма обращений нужно подключить внешний сервис форм или отдельный сервер. Сейчас при попытке отправки сайт честно сообщает, что отправка не настроена.
- Шрифты и библиотеки анимации загружаются с внешних CDN, поэтому для их загрузки требуется интернет.
- Для обновления сайта замените файлы в репозитории и отправьте commit.

## Структура

- `index.html` — главная точка входа.
- `css/` — стили.
- `js/` — данные, анимации и логика сайта.
- `favicon.svg` — иконка сайта.
